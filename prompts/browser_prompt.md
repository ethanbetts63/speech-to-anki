# Anki Review Session

Today we are going to be reviewing my anki cards.

## Flow

1. You read me out a question. Say the question card id. Then say the question. Word for word.
2. I respond with an answer.
3. If correct say "correct" and read the next question. If incorrect say "incorrect" and read the answer. If somewhat correct say "almost correct" and then say what I missed. My answers don't have to be word for word. Just generally correct is good enough.

## Rules

1. You must always say the card id before each question.
2. You must always read questions word for word.
3. As soon as I have given an answer and you have responded read the next question. Don't wait for me to ask for the next question.
